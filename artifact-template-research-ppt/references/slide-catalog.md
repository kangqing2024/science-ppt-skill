# 20页可编辑版式目录

文件：`../assets/reference.pptx`；总览：`layout-atlas.jpg`。20页是组件目录，不是固定成品页数或顺序。

| 页 | 版式 | 用法 |
|---|---|---|
| 1 | 封面 | 主题横带、题目、汇报信息；换真实标识或删标识 |
| 2 | 编号目录 | 改为本次4–6章，与导航同步 |
| 3 | 章节过渡 | 长报告可用，短组会省略 |
| 4 | 背景图文 | 左需求/进展/瓶颈，右证据图，底部研究必要性 |
| 5 | 研究现状对比 | 原生表格；方向/来源/进展/不足 |
| 6 | 科学问题 | 已有认识与未知，底部核心问题 |
| 7 | 目标与内容 | 总目标+并列任务，数量按材料调整 |
| 8 | 技术路线主图 | 大图位；真实图用Visio，保留VSDX |
| 9 | 实验设计与指标 | 原生表格；任务/方法/对照/指标 |
| 10 | 双图结果证据 | 主要结果与验证，来源及结论 |
| 11 | 基础/可行性 | 左文字右结果或平台 |
| 12 | 计划里程碑 | 原生表格；阶段/任务/交付/时间 |
| 13 | 编号创新点 | 每项一个具体区别及依据，数量可变 |
| 14 | 总结与后续 | 结论、局限、下一步和讨论问题 |
| 15 | 致谢 | 与封面统一，联系信息可选 |
| 16 | 海军蓝左侧导航 | 文献正文原型；复制后调整正文，不加顶部导航 |
| 17 | 绿色样式 | 供选色；成品删除“变体”标签 |
| 18 | 紫色样式 | 同上，整套同步选色 |
| 19 | 项目标题栏/风险表 | 原生表格；项目页眉默认参考这页 |
| 20 | 任务时间矩阵 | 原生表格式甘特图；填实际阶段和依赖 |

先定场景和页眉，再选内容页，重复必要证据页，删无关页；同步章节名、编号、高亮、页码、简称。跨用目录页时统一主色和页眉，不能把五种展示风格混成正式报告。

页4–14、20有顶部导航。切换项目横栏时用页19页眉，去掉原导航并调整内容位置；切换左导航时参考页16，将正文右移、缩窄并重新检查图文，不用侧栏覆盖旧内容。页19的风险表可以替换为其他内容页的分区布局。

保留文本框、表格等原生对象；图位按材料换图。页8只是占位框，不含真实科研方法；方法/模型图按用户偏好保留Visio源文件。原型主要对象在幻灯片层，不能误称为20个原生母版。

左侧导航的图层从后到前固定为“侧栏背景—高亮矩形—全部导航文字”。切换章节时移动高亮并调整文字字重，不能让高亮盖住旧位置之前的标签；逐页核对六个章节名全部可见。
