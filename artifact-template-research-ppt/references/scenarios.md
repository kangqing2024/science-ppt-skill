# 按场景组织内容

以下是本地样本的可复用结构，章节与页数随材料调整。页码均为原PPT物理页码，用于说明结构，不授权迁入旧项目事实。

| 场景 | 内容链 | 重点 |
|---|---|---|
| 文献/组会 | 文献信息、背景、问题与思路、按结论递进的结果、结论局限、对本组启发 | 左侧导航；图和解释一起；一项结论可多页递进 |
| 开题 | 背景现状、科学问题、目标内容、设计/路线、创新、前期基础/可行性、进度成果 | 顶部导航；区分已有与拟开展工作 |
| 基金 | 立项依据、内容方案、特色创新、计划成果、基础平台 | 项目标题栏；问题/任务/方法/指标对应 |
| 重点研发 | 背景需求、目标路线、课题分解、任务进度、团队基础、组织、成果考核、风险 | 每课题目标/内容/指标；原生任务表格 |
| 结题/报奖 | 需求瓶颈、创新与证据、指标完成、推广、可核查效益、限制及后续 | 已完成须有证据；效益只用真实材料 |
| 人才/团队 | 个人/团队基础、代表成果、拟开展工作、支撑条件 | 只有此场景默认加入履历/团队清单 |

原件依据：

- 海军蓝：p2六章；p7–25连续结果，p26结论、p27不足、p28创新启发。
- 浙大蓝：p2目录、p7问题、p8内容、p9–11设计/指标、p12创新、p13–16基础/可行性、p17进度。
- OD3：p3目录、p8–11目标/内容/方法、p13创新、p18进度。
- 联合基金：p2目录、p10路线、p12特色/创新、p14进度、p15预期、p17平台。
- 38页重点研发：p18–20每课题目标/内容/指标、p21进度、p25既往项目、p27组织、p29考核、p31风险。
- 绿色基金与科技奖：需求/瓶颈、创新及应用效益；绿色p2三章、p3–7背景、p9–14创新、p16效益。

文献不自动加入履历、效益和团队规模；申报不把目标写成已证实结果。缺图时按用户要求交空白图位；要求完整报告但关键资料缺失时，准确指出缺项并推进其他页面。

背景/方法用简明主题标题，结果在证据支持时用具体发现。主线在脑中或极简页面清单确定，不为普通报告新增多份流程文件。
